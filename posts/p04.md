## O que é um Histograma de Imagem Digital?

Histograma é uma maneira de retratar dados em forma de gráfico.

Pensando em um histograma de imagem digital, é um maneira de representar a distribuição de valores de uma imagem aplicando seus dados no gráfico:
* Eixo X: Diferentes níveis de intensidade de cada pixel de uma imagem, onde 0 -> preto e 255 -> branco.
* Eixo Y: Número de vezes que cada intensidade aparece na imagem.

---

Supondo uma imagem, **EM TONS DE CINZA**, com as seguintes distribuições:

| Intensidade | Quantidade de pixels |
| ----------: | -------------------: |
|           0 |                   10 |
|          50 |                    5 |
|         100 |                   20 |
|         150 |                   40 |
|         200 |                   20 |
|         255 |                    5 |

O histograma equivalente seria:

```text
Quantidade
de pixels
   │
40 │             █
   │             █
30 │             █
   │             █
20 │       █     █     █
   │       █     █     █
10 │ █     █     █     █
   │ █     █     █     █     █
   └────────────────────────────
     0    50   100   150  200  255
             Intensidade
```

## Avaliação de um Histograma

É possível definir a "cara da imagem" so de bater o olho no histograma, e vice-verso. 
* Concentração de dados no lado esquerdo do histograma -> Normalmente imagens mais escuras.
* Concentração de dados no lado direito -> Normalmente imagens mais claras.

## Normalização de Histograma

Vamos pensar que estamos comparando duas imagens, mas elas tem tamanho diferente. Logo a quantidade de pixels total de cada uma delas é também é diferente:

- Imagem 1: 3.000.000 pixels
- Imagem 2: 50.000 pixels

A comparação dos histogramas naturalmente será discrepante, mas podemos arrumar isso com a **Normalização**, utilizando porcentagem junto da a seguinte formula:

$$
p(r_k) = \frac{n_k}{M \times N}
$$

Onde:

- $r_k$ representa a intensidade em tratamento.
- $n_k$ representa o número de pixels com intensidade $r_k$;
- $M \times N$ representa o número total de pixels da imagem.

Imagine:

- Imagem 1: 3.000.000 pixels
- Intensidade 100: 400.000 pixels

Então:

$$
p(100) = \frac{400.000}{3.000.000}
$$


$$
p(100) =~ 0,13 = 13%
$$ 

13% dos pixels da imagem possuem intensidade 100.

## Equalização de Histograma

O nome é intuitivo: serve para redistribuir os níveis de intensidade de uma imagem através da **função de distribuição acumulada (CBF)**.


Exemplo:

```text
ANTES

0 ─────────────────────────── 255
       █████████████
       █████████████
       █████████████


             ↓
        EQUALIZAÇÃO
             ↓


DEPOIS

0 ─────────────────────────── 255
   ███    ███    ███    ███
   ███    ███    ███    ███

```
Produz como saída uma imagem que tenha um histograma uniforme, fazendo melhor uso do intervalo de intensidades disponíveis.
