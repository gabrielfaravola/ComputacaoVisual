## O que é um histograma de imagem digital?

Histograma é uma maneira de retratar dados em forma de gráfico.

Pensando em um histograma de imagem digital, é um maneira de representar a distribuição de valores de uma imagem aplicando seus dados no gráfico:
* Eixo X: Diferentes níveis de intensidade de cada pixel de uma imagem, onde 0 -> preto e 255 -> branco.
* Eixo Y: Número de vezes que cada intensidade aparece na imagem.

Supondo uma imagem, **EM TONS DE CINZA**, com as seguintes distribuições:
| Intensidade | Quantidade de pixels |
| ----------: | -------------------: |
|           0 |                   10 |
|          50 |                    5 |
|         100 |                   20 |
|         150 |                   40 |
|         200 |                   20 |
|         255 |                    5 |

## Avaliação de um Histograma

É possível definir a "cara da imagem" so de bater o olho no histograma, e vice-verso. 
* Concentração de dados no lado esquerdo do histograma -> Normalmente imagens mais escuras.
* Concentração de dados no lado direito -> Normalmente imagens mais claras.
