## Interpolação de imagens

Quando damos zoom em uma imagem, a resolução padrão de uma imagem fica "desregulada" e passam a existir mais pixels para representar um mesmo elemento da imagem. Quando tiramos o zoom, teremos menos pixels para representar esse mesmo elemento. O algoritmo responsável por fazer essa correção é o de **interpolação**.

É uma função que estima valores de um pixel com base nos pixels vizinhos: cima, baixo, esquerda, direita e diagonais.

## Como funciona?

A interpolação da imagem é definida a partir dos pixels já existentes, utilizando seus valores e suas posições para estimar os valores necessários na nova configuração da imagem.

Existem diferentes métodos de interpolação, que determinam de maneiras diferentes como esses valores serão estimados.

### Vizinho mais próximo

O método de **vizinho mais próximo** utiliza o pixel original que está mais próximo da posição que precisa ser preenchida.

É um método simples e rápido, porém pode gerar uma aparência mais **pixelada** quando a imagem é ampliada.

### Interpolação linear

A **interpolação linear** estima um valor localizado entre dois valores conhecidos.

A ideia é calcular uma transição entre esses dois valores, levando em consideração a posição do ponto que queremos estimar.

$$
V = (1-\alpha)V_0 + \alpha V_1
$$

Onde:

- $V_0$ e $V_1$ são os valores conhecidos;
- $\alpha$ determina a posição do valor estimado entre eles.

### Interpolação bilinear

A **interpolação bilinear** aplica a ideia da interpolação linear em duas dimensões.

Em vez de considerar apenas dois valores, são considerados os **quatro pixels vizinhos** ao ponto que queremos estimar.

```text
Q11 ───────── Q21
 │             │
 │      P      │
 │             │
Q12 ───────── Q22
```


O processo ocorre em duas etapas:

- Interpolação horizontal entre os pixels;
- Interpolação vertical utilizando os resultados obtidos.

Dessa forma, o valor de um pixel pode ser estimado considerando a influência dos quatro pixels ao seu redor.

## 💡 Conclusão

A interpolação é utilizada para estimar valores de pixels durante transformações de uma imagem, principalmente quando a quantidade ou a posição dos pixels precisa ser alterada.

Os principais métodos vistos são:

- Vizinho mais próximo → utiliza o pixel mais próximo
- Linear → estima entre dois valores
- Bilinear → estima utilizando quatro pixels vizinhos
